Prerequisites & Toolchain Setup

To compile and execute real C++ code natively on your machine, you need a C++ compiler (GCC or Clang) and optionally VS Code. Run these one-line commands in your terminal:

Windows (PowerShell)

1. MinGW-w64 (GCC Compiler)
winget install -e --id MSYS2.MSYS2

Alternative (LLVM/Clang): winget install -e --id LLVM.LLVM

2. Visual Studio Code
winget install -e --id Microsoft.VisualStudioCode
3. Node.js (Companion Server Runtime)
winget install -e --id OpenJS.NodeJS.LTS

macOS (Terminal)

Apple Clang Compiler & VS Code
xcode-select --install && brew install --cask visual-studio-code

Linux (Ubuntu / Debian)

Build Tools & VS Code
sudo apt update && sudo apt install -y build-essential gdb && sudo snap install --classic code
